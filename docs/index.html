Que tu flujo
te cuente algo

Hoy hicimos que los datos viajen entre las cajitas. El reto de esta semana es que tu flujo salga a buscar un dato a internet y lo cuente con tus palabras.

El reto

Tres cajitas, nada más

  1. Un disparador. A mano (Trigger manually) alcanza. Si te animás, poné uno programado.
  2. Un HTTP Request. Método GET y la dirección de la API que elijas de acá abajo.
  3. Un Edit Fields. Creá un campo frase, pasalo a Expression y armá una oración que mezcle tu nombre con el dato que trajiste.

Qué entregás

Una captura del flujo corrido, con la frase final visible. Y una línea contando qué API elegiste y por qué ésa.

Hasta el miércoles 9 de septiembre, en Classroom. No importa si tu frase termina siendo una tontera: importa que el dato haya viajado.

La chuleta

Cómo se saca un dato

Entre dobles llaves. Un punto por cada nivel al que entrás: los puntos son el camino hasta el dato.

{{ $json.current.temperature_2m }}

Si en el campo ves las llaves tal cual en vez del valor, el campo quedó en modo Fixed: buscá el botoncito Fixed / Expression y pasalo a Expression.

Para no quedarte trabada

Flujos listos, para copiar y pegar

Si algo no te sale, agarrá el flujo hecho y seguí. No es hacer trampa: abrirlo y ver por dentro por qué funciona enseña tanto como armarlo.

1
La más rápida

Tocá Copiar el flujo y pegá con Ctrl + V sobre el lienzo de n8n. Te va a preguntar Import Workflow? — dale Yes, import.

2
Desde la dirección

Tocá Copiar el link. En n8n, arriba a la derecha, el menú de los tres puntos → Import → From URL, y pegala.

3
Desde el archivo

Tocá Bajar. Después en n8n: Import → From file y elegí el que bajaste.

Ninguno pide cuenta ni clave: los importás y se ejecutan. Si te pide credenciales, algo se pegó mal — borralo y probá de nuevo.

Va a pasar, y está bien

Si algo se rompe

Aparecen las llaves tal cual

El campo quedó en Fixed. Pasalo a Expression.

undefined

Ese dato no existe en la bandeja. Mirá la pestaña INPUT: ahí está lo que de verdad llegó.

La cajita se pone roja

El servicio contestó un error. Abrila y leé el mensaje: casi siempre es la dirección mal copiada.

401 · Unauthorized

Esa API pide una clave y no se la diste. Las cinco primeras de acá arriba no piden nada.
